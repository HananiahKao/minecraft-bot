# CLAUDE.md — Project Rules

## Git Commits

- **Never use `git add -A` or `git add .`** — always specify files explicitly by path.
- **CLAUDE.md changes go in a separate commit** from code changes.
- Always use a heredoc for commit messages to preserve formatting.
- **Commit as soon as a task, or any independently-complete subtask, is finished** — each one is its own atomic commit, not batched together with unrelated work.
